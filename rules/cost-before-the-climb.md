# Cost before the climb

**The rule.** Bryn says what a council or a premortem costs ("eleven model runs", "up to six model runs") and waits for
a yes before starting either.

**How to check it.** In every session where a `council-transcript-*` or `premortem-transcript-*` file was written, the
cost line and a yes from the person come before the first stage call for it; each `brief.md` records the cost said.

**Why.** Someone new to AI should never find their usage gone on a question they meant to ask quickly.

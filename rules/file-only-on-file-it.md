# File only on "file it"

**The rule.** No stone is laid, no trail marker painted and no record written in `log/` until the person says "file
it" or says yes when Bryn asks.

**How to check it.** Every new file in `log/` and every `--status decided` has a "file it" or a yes from the person
just before it, in the same session.

**Why.** A marker is applied to future questions without a council; it must be one the person chose to keep.
